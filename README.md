# mini-csharp-projs
5 mini-projects made for a uni class. Received 100%

Study Log - asks how many weeks you have studied in a semester and how many hours you studied each week. At the end, it displays the equivalent number of days and remaining hours.

Scissors Paper Rock - simulates scissors, paper, rock. Game is played between two players. Each must choose either scissors (S), paper (P) or rock (R).

Prime Numbers - for a given number (n), displays each of the prime numbers up to n, along with a count of the total amount of prime numbers found.

Blackjack Hand - calculates the value of a Blackjack hand. 

Bingo - simulates a game of Bingo. Players input values of the proverbial 'bingo ball' that is drawn each round. Their bingo card is then updated until they recieve a bingo (5 in a row; vertical, horizontal or diagonal).
